# Attribution

MoneyWiz MCP Server is a derivative of the open-source project [`jcvalerio/moneywiz-mcp-server`](https://github.com/jcvalerio/moneywiz-mcp-server), created by Juan Carlos Valerio Arrieta and contributors.

This repository retains the original Git history so authorship, provenance, and upstream development remain visible. The hardened 2.x line started from upstream commit `d113a11df8ea475f50b5d118585c763bb4f5ba72` and keeps the original MIT license.

The 2.x work substantially changes the implementation while preserving the original project's purpose. Major changes include migration to the official MCP Python SDK v2, permanent read-only SQLite access, dynamic Core Data schema discovery, deterministic monetary and currency semantics, explicit completeness/error handling, stronger privacy controls, a reconciliation harness, and expanded regression testing.

Thank you to Juan Carlos Valerio Arrieta and the upstream contributors for creating the original project and making it available under the MIT License.
