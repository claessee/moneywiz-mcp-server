# Code of Conduct

## Our standard

Participation in this project should be professional, respectful, and focused on improving the software. Contributors are expected to discuss ideas and technical disagreements without personal attacks, harassment, discrimination, intimidation, or deliberate disruption.

Examples of constructive behavior include providing reproducible evidence, reviewing code rather than people, acknowledging uncertainty, and helping others correct mistakes without hostility.

Examples of unacceptable behavior include harassment, threats, discriminatory language, publishing another person's private information, or intentionally posting private financial data belonging to someone else.

## Financial-data privacy

This project works with personal financial databases. Never post another person's MoneyWiz database, balances, transactions, credentials, or other private financial information without their explicit permission. Public bug reports should use synthetic or sanitized examples.

## Enforcement

Repository maintainers may edit or remove comments, issues, pull requests, code, or other contributions that violate these expectations and may restrict participation when necessary to protect contributors or the project.

If a conduct concern cannot be raised safely in public, use an available private GitHub contact/security mechanism rather than disclosing sensitive details publicly.
